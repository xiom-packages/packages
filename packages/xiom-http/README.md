# xiom.http

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** HTTP/1.1 and HTTP/2 client/server with routing.
> **Deps:** stdlib; may wrap C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `http-client` | HTTP client with pooling and redirects. |
| `http-server` | HTTP server with request handling and middleware. |
| `request` | Request parsing, headers, and body streaming. |
| `response` | Response status, headers, and body streaming. |
| `cookie` | Cookie parsing and serialization. |
| `router` | Path- and method-based route matching. |
