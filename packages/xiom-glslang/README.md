# xiom.glslang

glslang (Khronos GLSL/ESSL/HLSL compiler) bindings for XIOM.

`xiom.glslang` is a **dynamic-loader binding**: it does not link against
glslang at build time.  `glslang_load()` resolves `glslang.dll` through
`xiom.ffi.dl` at runtime and `glslang_load_resource_limits()` resolves
`glslang-default-resource-limits.dll`; when the libraries are absent the
conformance suite reports SKIP and stays green.  Verified against the
glslang **16.3.0** build shipped with Vulkan SDK 1.4.350.0.

> **Status:** `incubating` -- 29/29 x2 on v0.64.4 (resolved=61/61);
> 0.1.0 published in `eco-v0.1.162` (sha256 `33898cf6...`).

## What is bound

- **C interface** (`Include/glslang_c_interface.h`, 41 entry points): the
  complete compile path -- shader create/preprocess/parse, program
  create/add/link, I/O mapping, SPIR-V generation, owned-buffer SPIR-V
  copy-out, mapper/resolver helpers, log string getters.
- **Legacy extern "C"** (`Public/ShaderLang.h`, 16 entry points):
  `ShInitialize`/`ShFinalize`, `ShConstructCompiler`/`Linker`/`UniformMap`,
  `ShDestruct`, `ShCompile`, `ShLinkExt`, attribute-binding setters,
  `ShGetUniformLocation`, `StageName`.
- **C resource-limits helpers** (`Public/resource_limits_c.h`, 4 entry
  points in the companion DLL): `glslang_resource`, `glslang_default_resource`,
  `glslang_default_resource_string`, `glslang_decode_resource_limits`.
- **290 generated constants**: every enum value of the C headers plus the
  legacy ESh*/EProfile/T* enums and the `GLSLANG_VERSION_*` macros
  (source-generated by `tools/gen_glslang.ps1`; drift-checked).

The C++ API (TShader/TProgram) is NOT an FFI surface -- upstream's C
interface wraps the same compile path and is what this package binds.
See `docs/COVERAGE.md` for the oracle/bound/resolved counts (61/61 C entry
points resolved at runtime).

## Usage

```xiom
use xiom.glslang;

let l = glslang_load();
if l.is_ok {
  let lib: GlslangLibrary = l.value;
  var ig = glslang_initialize_process(&lib);

  let lr = glslang_load_resource_limits();
  let lim: GlslangResourceLimitsLibrary = lr.value;
  let resource = glslang_default_resource(&lim);   // 0 on failure

  let src = "#version 450\nvoid main() { gl_Position = vec4(0.0); }\n";
  let msgs = GLSLANG_MSG_SPV_RULES_BIT | GLSLANG_MSG_VULKAN_RULES_BIT;
  let spirv = glslang_compile_glsl_to_spirv(&lib, src, GLSLANG_STAGE_VERTEX,
    GLSLANG_TARGET_VULKAN_1_0, msgs, resource, 450);
  if spirv.is_ok {
    var words: Vec[UInt8] = spirv.value;   // owned SPIR-V byte buffer
    // ... upload to Vulkan ...
  }

  glslang_finalize_process(&lib);
  var ic = glslang_resource_limits_close(&lim);
  var ic2 = glslang_close(&lib);
}
```

Notes:

- Keep the companion library loaded while using its resource pointer (`closing
  it first dangles `glslang_default_resource()`).
- The manual pipeline (`glslang_input_glsl` -> `glslang_shader_create` ->
  `glslang_shader_preprocess` -> `glslang_shader_parse` -> program ->
  `glslang_program_spirv_words`) is available when you need per-step control
  or the info logs.
- Delete programs before the shaders linked into them.
