## Design notes

- **Licensing**: upstream SDL2 is zlib (permissive, whitelisted); no
  upstream code is copied or vendored -- the package is generated bindings
  over the public ABI.  Package license MIT OR Apache-2.0.  The shared
  clone lives at `E:\repos\SDL2` under the CLEANUP ledger (row reported to
  the coordinator; the ledger is owned by `E:\repos\CLEANUP.md`).
- **Confinement (G5)**: `unsafe` appears only in the generated cast-call
  blocks (`let f = syms.p_x as fn(...); f(...)`) in `sdl2.xi` and
  `src/*.xi`; no pointer arithmetic, no reads through foreign pointers.
  Out-params are XIOM-owned `Vec[UInt8]` slots handed to C via
  `as_mut_ptr()` and read back byte-indexed (B-11..B-20).
- **SKIP vs FAIL**: absent DLL -> SKIP (classified platform state, green);
  present DLL with a missing symbol -> `SDL2_LOAD_ABI` FAIL.  Never a
  silent skip.
- **Error mapping**: SDL2's `int` 0/-1/success conventions and
  `SDL_bool` (0/1) are surfaced as `Int`/`Str`; `SDL_GetError` reads the
  C string into an XIOM `Str` (NULL -> `""`).

## Known limitations (explicit)

- **Variadic functions** bind their fixed-arity prefix only (12 wrappers);
  4 `va_list` wrappers expose the handle as an opaque `Int`.  No varargs
  are ever passed from XIOM.
- **Callback typedefs** are typed `fn(...)` parameters; pointer payloads map
  to `Int`, floats to `Float32`.  Deep callback marshalling is not
  exercised by the suite (compile-bound + typed; probes avoid callbacks).
- **Declared-but-not-exported** (27) and **exported-but-not-declared** (1:
  `SDL_DYNAPI_entry`) are documented with proof in `docs/COVERAGE.md`; they
  are out of the win-x64 exported surface (or internal, respectively).
- **Header source**: the pin hashes the SDK-shipped header set (64 files,
  revision string `SDL-release-2.32.10-0-g5d2495703`); the upstream clone at
  `E:\repos\SDL2` was used to verify declaration semantics and the
  `SDL_MainIsReady`/audio-driver behavior referenced by the probes.
- One constant is unevaluable by construction:
  `SDL_WINAPI_FAMILY_PHONE` (WinRT config comparison, not a constant on
  win-x64); listed in `docs/gen_manifest.json`.
