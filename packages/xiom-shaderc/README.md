# xiom.shaderc -- shaderc C API bindings for XIOM

Dynamic-loader bindings for **shaderc** (the compiler library behind
`glslc`): compile GLSL/HLSL to SPIR-V, assemble SPIR-V text, preprocess
sources, and drive the full compile-options surface -- no SDK at build time,
`shaderc_shared.dll` resolved at runtime, SKIP-green when absent.

- **Coverage:** 100% of the public C API -- **45/45** `SHADERC_EXPORT`
  entry points and **191** enum constants, generated by a committed
  generator (`tools/gen_shaderc.py`) from the pinned headers.
- **Runtime:** `shaderc_shared.dll` (shipped with the Vulkan SDK; pinned
  upstream `google/shaderc` v2026.4, commit `b64fd42c`).
- **License:** MIT OR Apache-2.0 (bindings only; upstream is Apache-2.0 and
  nothing is vendored).

## Usage

```xiom
use xiom.shaderc;
use xiom.shaderc.constants;

let lr = shaderc_load();
if !lr.is_ok {
  // kind == SHADERC_LOAD_ABSENT -> SKIP on this machine
}
let lib = lr.value;
let compiler = shaderc_compiler_initialize(&lib);
let src = "#version 450\nvoid main() { gl_Position = vec4(0.0, 0.0, 0.0, 1.0); }\n";
let result = shaderc_compile_into_spv(&lib, compiler, src,
  shaderc_glsl_vertex_shader, "main.vert", "main", 0);
if shaderc_result_get_compilation_status(&lib, result) == shaderc_compilation_status_success {
  let word = shaderc_result_first_word(&lib, result);      // 0x07230203 (SPIR-V magic)
  let bytes = shaderc_result_copy_bytes(&lib, result, 64); // owned Vec[UInt8]
}
shaderc_result_release(&lib, result);
shaderc_compiler_release(&lib, compiler);
var ig = shaderc_close(&lib);
```

Options, error paths, assembly round trips and the SPIR-V version queries
work the same way; see `tests/test_conformance.xi` for every family.

## Run the suite

```powershell
# DLL present (Vulkan SDK Bin on PATH):
$env:PATH = "C:\VulkanSDK\1.4.350.0\Bin;" + $env:PATH
& scripts\port.ps1 -Package xiom.shaderc -TimeoutSec 700

# absent: filter the SDK Bin out of PATH -> SKIP-green (exit 0)
```

`port.args.json` supplies `--enable-unsafe-direct`; see SPEC.md §3 and
AUDIT.md for why the generated wrappers use the documented
`#[unsafe_direct]` escape hatch.
