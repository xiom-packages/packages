# xiom.realtime

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** Realtime scheduling, timing, and event loop utilities.
> **Deps:** stdlib; may wrap C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `realtime/clock` | Monotonic and deadline-aware clock abstractions |
| `realtime/loop` | Tick-based event and update loop primitives |
| `realtime/task` | Deferred and periodic task scheduling |
