# xiom.lz4

LZ4 compression bindings for XIOM at **100% declared surface** of `lz4.h` +
`lz4hc.h` + `lz4frame.h`.  The upstream library (**v1.10.0**, lib/
BSD-2-Clause) is vendored in `vendor/lz4/` and compiled into the test binary
-- no system library, no runtime DLL, no network at build time.

> **Status:** `incubating` -- suite green x2 on the pin (v0.64.4): 81/81
> (`scripts/port.ps1 -Package xiom.lz4 -TimeoutSec 600`).
> **Lane:** bindings (`keywords: ["binding"]`).
> **Published**: `0.1.0` in `eco-v0.1.178` (sha256 `7b106897...`).

## Quick start

```xiom
use xiom.io;
use xiom.convert;
use xiom.lz4;

fn main() {
  var src: Vec[UInt8] = Vec[UInt8].new();
  var i: Int = 0;
  while i < 4096 {
    src.push(((i % 64) + 65) as UInt8);
    i = i + 1;
  }

  // Block codec (fast, no framing).
  let packed = lz4_compress(&mut src, LZ4_ACCELERATION_DEFAULT);
  if !packed.is_ok {
    io.println("compress failed: " + packed.error.message);
    return;
  }
  var c: Vec[UInt8] = packed.value;
  io.println("block: " + to_string(c.len()) + "/4096 bytes");

  // Frame codec (xxHash checksums optional, interoperable .lz4 framing).
  var prefs = lz4f_prefs_new();
  lz4f_prefs_set(&mut prefs, LZ4F_MAX64KB, LZ4F_BLOCK_LINKED,
    LZ4F_CONTENT_CHECKSUM_ENABLED, 4096, 0, LZ4F_NO_BLOCK_CHECKSUM, 9, 0, 0);
  var src2: Vec[UInt8] = Vec[UInt8].new();
  var j: Int = 0;
  while j < 4096 {
    src2.push(((j % 64) + 65) as UInt8);
    j = j + 1;
  }
  let frame = lz4f_compress_frame(&mut src2, &mut prefs);
  if frame.is_ok {
    var f: Vec[UInt8] = frame.value;
    let back = lz4f_decompress(&mut f, 4096);
    if back.is_ok {
      io.println("frame: " + to_string(f.len()) + " bytes, checksummed");
    }
  }
}
```

## API

| Area | Entry points |
|------|--------------|
| Facade (`xiom.lz4`) | constants (`LZ4_VERSION_NUMBER`, `LZ4HC_CLEVEL_*`, `LZ4F_*` enums/error codes), `Lz4Error`, `lz4_version_number/string`, `lz4_compress`, `lz4_decompress`, `lz4hc_compress`, `lz4_compress_dest_size`, `lz4_compress_bound`, `lz4_decoder_ring_buffer_size`, slot builders (`lz4f_prefs_new`, `lz4f_frame_info_slot_new`, `lz4f_compress_options_new`, `lz4f_decompress_options_new`, `lz4f_custom_mem_new`), `lz4f_prefs_set`, `lz4f_compress_frame(_bound)`, `lz4f_decompress`, `lz4f_frame_info`, `lz4f_content_size`, error helpers (`lz4f_is_error`, `lz4f_error`, `lz4f_error_message`) |
| Complete 1:1 surface (`xiom.lz4.ffi`) | all **111** functions of `lz4.h` + `lz4hc.h` + `lz4frame.h` (66 stable, 34 deprecated, 11 static-linking-only), generated by `tools/gen_lz4_ffi.py` |

Wire types: opaque handles are `Int`; buffers and struct slots are owned
`Vec[UInt8]` (`&mut`, zeroed slots equal upstream defaults); float-free API.
See SPEC.md sec. 3 for the pin-specific rules (pointer values never
round-trip through XIOM; C `int` returns sign-extend via `Int32`).

## Coverage

`docs/COVERAGE.md`: 111/111 declared functions bound 1:1; 109 exercised by the
suite, 2 obsolete `*_withPrefix64k` entries documented as bound-but-skipped
(their 64 KB-prefix precondition needs pointer arithmetic, which is confined
to C).
