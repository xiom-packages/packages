headers and the committed generated artifacts. The conformance suite asserts
`HB_SURFACE_TOTAL == xhb_symbol_count()` and that the C-side FNV-1a name hash
equals `HB_SURFACE_NAME_HASH` (declaration order fixed by the generator).
