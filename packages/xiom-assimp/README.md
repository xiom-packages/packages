# xiom.assimp

Open Asset Import Library (assimp **v6.0.5**) bindings for XIOM. A pinned
**subset** (core + OBJ/STL/PLY/**glTF2** importers + zlib/earcut/utf8/
rapidjson contribs) is vendored into `vendor/` and generated by
`tools/combine.py`; the compiled TUs ride in `port.args.json`. No system
library, no SDK.

> **Status:** `incubating` -- conformance suite green on the pin (xiom
> v0.64.2; 5/5 x2, real in-memory OBJ + PLY + glTF2 imports). Published in
> `eco-v0.1.128` (sha256 `5b30c6a8...`; 0.2.0 remains in `eco-v0.1.127`).
> **Lane:** bindings (`keywords: ["binding"]`).

## Quick start

```xiom
use xiom.io;
use xiom.assimp;

fn main() {
  io.println("assimp " + assimp_version_str(assimp_version()));

  let p = assimp_probe();          // imports built-in OBJ + PLY assets
  if p.is_ok {
    io.println("imports ok");      // p.value.obj_meshes / obj_vertices / ...
  } else {
    io.println(p.error);
  }
}
```

## API

| Area | Functions |
|------|-----------|
| Version | `assimp_version` (packed), `assimp_version_str` |
| Probe | `assimp_probe` -> `AssimpInfo` (obj_meshes/obj_vertices/obj_faces/ply_vertices/gltf_vertices) |

Details + the subset/pin policy: `SPEC.md`. More importers, post-processing
wrappers, and the export API are Phase 2 (`ROADMAP.md`).
