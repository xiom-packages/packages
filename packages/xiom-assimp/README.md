# xiom.assimp

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** Asset Import Library 3D model import/export bindings.
> **Deps:** stdlib; wraps C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `import` | Model file loading |
| `export` | Model file writing |
| `scene` | Imported scene graph |
| `mesh` | Mesh data access |
| `material` | Material properties |
| `animation` | Animation channels |
