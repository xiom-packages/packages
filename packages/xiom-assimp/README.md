# xiom.assimp

Open Asset Import Library (assimp **v6.0.5**) bindings for XIOM. A pinned
**subset** (core + OBJ/STL/PLY/**glTF2**/**COLLADA**/**FBX**/**BLEND**/
**OFF**/**SMD** importers + zlib/earcut/utf8/rapidjson/pugixml/poly2tri
contribs) is vendored into `vendor/` and generated by `tools/combine.py`;
the compiled TUs ride in `port.args.json`. No system library, no SDK.

> **Status:** `incubating` -- conformance suite green on the pin (xiom
> v0.64.3; **16/16 native**: the eight in-memory imports -- OBJ + PLY +
> glTF2 + COLLADA + FBX + OFF + SMD + BLEND fixture -- plus the 0.8.0
> file-import group (import_file -> handle, mesh counts, positions/uvs/
> indices copies, release, missing-file Err) on `tests/fixtures/quad_uv.obj`.
> 0.8.0 targets the engine P4 asset pipeline. **Lane:** bindings
> (`keywords: ["binding"]`).

## Quick start

```xiom
use xiom.io;
use xiom.assimp;

fn main() {
  io.println("assimp " + assimp_version_str(assimp_version()));

  let p = assimp_probe();          // imports the built-in format probes
  if p.is_ok {
    io.println("imports ok");      // p.value.obj_meshes / obj_vertices / ...
  } else {
    io.println(p.error);
  }
}
```

## API

| Area | Functions |
|------|-----------|
| Version | `assimp_version` (packed), `assimp_version_str` |
| Probe | `assimp_probe` -> `AssimpInfo` (obj_meshes/obj_vertices/obj_faces/ply_vertices/gltf_vertices/collada_vertices/fbx_vertices/blend_meshes/blend_vertices/blend_faces/off_meshes/off_vertices/off_faces/smd_meshes/smd_vertices/smd_faces) |
| File import (0.8.0) | `assimp_import_file(path)` -> `Result[handle, Str]` (Triangulate + FlipUVs; 4 live imports), `assimp_release(handle)`, `assimp_mesh_count`, `assimp_mesh_vertex_count`, `assimp_mesh_triangle_count`, `assimp_mesh_has_uvs`, `assimp_mesh_positions` -> `Vec[Float64]` (xyz), `assimp_mesh_uvs` -> `Vec[Float64]` (uv; empty when absent), `assimp_mesh_indices` -> `Vec[UInt32]` (3 per triangle) |

Details + the subset/pin policy: `SPEC.md`. The engine asset-pipeline
consumer contract (stability promise, error surface, threading):
`CONTRACT.md`. More importers, post-processing wrappers, and the export API
are Phase 3 (`ROADMAP.md`).
