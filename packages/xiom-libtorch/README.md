# xiom.libtorch

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** LibTorch C++ frontend bindings for PyTorch models.
> **Deps:** stdlib; may wrap C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `torch` | Core LibTorch tensor API. |
| `nn` | Module and layer bindings. |
| `optim` | Optimizer bindings. |
| `cuda` | CUDA device bindings. |
| `jit` | TorchScript JIT engine. |
