# xiom.glfw

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** GLFW windowing and input bindings.
> **Deps:** stdlib; wraps C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `window` | Window creation and events |
| `context` | OpenGL/Vulkan context management |
| `input` | Keyboard, mouse, and joystick input |
| `monitor` | Display and video mode access |
| `event` | Window event polling |
