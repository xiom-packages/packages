# xiom.slang -- Slang C API bindings for XIOM

Dynamic-loader bindings for the [Slang](https://github.com/shader-slang/slang)
shader compiler C API shipped with the Vulkan SDK (1.4.350.0, runtime tag
2026.8): **every C entry point the DLL exports** -- the modern `slang_*` API
and the legacy `sp*` compile API -- resolved by name at runtime with typed
wrappers. No link-time dependency, no vendored code.

- **277 / 277 exported C functions bound and resolved** (`resolved=277/277`
  at runtime), generated by `tools/gen_slang.py` from the pinned headers and
  the DLL export table (see `docs/COVERAGE.md` for the airtight counts).
- **382 constants**: every `SLANG_*` enum entry (incl. the X-macro
  `SLANG_IMAGE_FORMAT_*` family) plus the integer macros.
- **SKIP-green**: with no `slang.dll` on the machine the suite reports
  SKIP and exits 0; a present-but-incomplete DLL is a hard failure.

> **Status:** `incubating` -- 20/20 x2 on v0.64.4 (resolved=277/277);
> 0.1.0 published in `eco-v0.1.162` (sha256 `0dd5548d...`).

## Quick start

```xiom
module demo

use xiom.io;
use xiom.convert;
use xiom.collections;
use xiom.slang;
use xiom.slang.wrap_legacy_top_p1;
use xiom.slang.wrap_legacy_top_p2;

// helpers (the same shapes the conformance suite uses)
fn cptr(s: Str) -> Int
  requires: true
{
  unsafe {
    return s.c_str() as Int;
  }
}

fn slot_new(n: Int) -> Vec[UInt8] {
  var s: Vec[UInt8] = Vec[UInt8].new();
  var i: Int = 0;
  while i < n {
    s.push(0 as UInt8);
    i = i + 1;
  }
  return s;
}

fn slot_u64(s: &Vec[UInt8]) -> Int
  requires: s.len() >= 8
{
  var my_v = 0;
  var my_i = 7;
  while my_i >= 0 {
    my_v = my_v * 256 + (s[my_i] as Int);
    my_i = my_i - 1;
  }
  return my_v;
}

fn main() -> Int {
  let loaded = slang_load();
  if !loaded.is_ok {
    io.println("slang unavailable: " + loaded.error.message);
    return 1;
  }
  let lib = loaded.value;

  let tag = sp_get_build_tag_string(&lib.legacy_top_p1);
  io.println("Slang build: " + tag);

  let session = sp_create_session(&lib.legacy_top_p1, 0);
  let request = sp_create_compile_request(&lib.legacy_top_p1, session);
  let target = sp_add_code_gen_target(&lib.legacy_top_p1, request, SLANG_SPIRV);
  let tu = sp_add_translation_unit(&lib.legacy_top_p1, request, SLANG_SOURCE_LANGUAGE_HLSL, cptr(""));
  sp_add_translation_unit_source_string(&lib.legacy_top_p1, request, tu,
    cptr("demo.hlsl"), cptr(
      "float4 main(uint id : SV_VertexID) : SV_Position { return float4(0,0,0,1); }"));
  sp_add_entry_point(&lib.legacy_top_p1, request, tu, cptr("main"), SLANG_STAGE_VERTEX);

  let rc = sp_compile(&lib.legacy_top_p1, request);
  var size_slot = slot_new(8);
  let code = sp_get_entry_point_code(&lib.legacy_top_p2, request, 0,
    unsafe { size_slot.as_mut_ptr() as Int });
  io.println("compile rc=" + to_string(rc) + " code size=" + to_string(slot_u64(&size_slot)));

  sp_destroy_compile_request(&lib.legacy_top_p1, request);
  sp_destroy_session(&lib.legacy_top_p1, session);
  let ig = slang_close(&lib);
  return 0;
}
```

Runtime requirement: `slang.dll` (and the `slang-compiler.dll` it forwards
to) must be reachable through the DLL search path. With the Vulkan SDK
installed, prepend `C:\VulkanSDK\1.4.350.0\Bin` to PATH.

## Layout

| Path | Content |
|------|---------|
| `slang.xi` | `xiom.slang` loader: `slang_load` / `slang_close` / `slang_resolved_count`, `SlangLibrary` |
| `src/gen_syms.xi` | symbol table (`SLANG_SYMBOLS`, `SLANG_SYMBOL_COUNT`) + header-only list |
| `src/gen_types.xi` | C typedef aliases (`SlangResult`, `SlangInt`, ...) |
| `src/res_*.xi` | per-family resolver + per-name count probe (12 families) |
| `src/wrap_*.xi` | typed wrappers, one per exported function (277) |
| `src/gen_const_*.xi` | `pub const` enum/macro literals (382) |
| `tests/test_conformance.xi` | conformance suite (resolved=N/N + functional probe) |
| `tools/gen_slang.py` | committed deterministic generator (headers + PE export table) |
| `docs/COVERAGE.md` | oracle/bound/resolved counts, export-vs-header split, commands |

All generated modules carry a `AUTO-GENERATED ... DO NOT EDIT` banner;
regenerate with:

```powershell
python packages\xiom-slang\tools\gen_slang.py
```
