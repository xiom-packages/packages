# xiom.openssl

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** OpenSSL FFI bindings for crypto primitives.
> **Deps:** stdlib; may wrap C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `evp` | EVP digest and cipher bindings |
| `x509` | X.509 certificate bindings |
| `rsa` | RSA key and signature bindings |
| `rand` | Secure random source binding |
