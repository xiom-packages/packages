- `callable` = the binding executes the function on this host (bridge-compiled CPU
  path, runtime-resolved unified API when a signed effect DLL is present, or the
  header-inline loader helper).
- `metadata` = source-level declaration bound as an introspectable record with a
  deterministic typed runtime classification: the signed 2.3.0 binaries export the
  provider-based unified API only, while the legacy host APIs are compiled into
  consumers from source. The binding resolves each name at runtime and reports the
  typed result; nothing is silently dropped (skips = 0).
- CAS and LPM are absent from the pinned headers (the 2.x SDK moved past the
  image-processing kit); they are out of the declared surface by construction.
- The dx12 backend descriptor headers (`api/include/dx12/`, `framegeneration/
  include/dx12/`) are parsed for metadata but not compiled into the ABI oracle
  (they need the DirectX-Headers SDK); their layouts use pointer-only external
  types, so the computed offsets are exact.
