# xiom.ffi

> **Status:** `incubating` -- not yet conformance-tested; not yet published to the XIOM registry.
> **Scope:** Safe foreign-function interface bindings to C libraries.
> **Deps:** stdlib; may wrap C (FFI).

## Libs inventory

| Lib | Description |
|-----|-------------|
| `ffi/bind` | Declarative extern binding generation |
| `ffi/call` | Type-checked foreign function invocation |
| `ffi/memory` | Managed allocation and pointer handling across the boundary |
